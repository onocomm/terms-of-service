# オノコムメンバーズ契約約款

**制定日**: 2026年11月12日
**施行日**: 2026年11月12日
**版**: 第1版
**株式会社オノコム**

## 第1条（適用及びサービス仕様書）

1. 本約款は、2026年11月12日以降に、株式会社オノコム（以下「当社」といいます）のポータルサイトから新規に申し込み、当社が承諾するオノコムメンバーズ契約（以下「本契約」といいます）に適用します。既に署名その他の方法により成立した契約の内容を自動的に変更するものではありません。
2. サービスの内容は、当社が公開する[オノコムメンバーズ サービス仕様書](https://github.com/onocomm/onocomm-members-docs/blob/56ba428fdd40da36668ad670c1e12c12c8d03b02/README.md)のうち、申込時に本文と版を固定して提示する内容によります。本約款は、仕様書に定めのないオンライン申込、契約期間、課金開始、解約可能時期及び合意記録等を補完します。仕様書に具体的な定めがある事項は仕様書を優先します。
3. 本約款及び前項のサービス仕様書の具体的な定めは、オノコムサービス契約約款（以下「基本約款」といいます）に優先します。両文書に定めのない事項は基本約款によります。他サービスの契約及び利用条件は、当該サービスに適用する文書によります。
4. サービス内容の変更は当社のサービス仕様書を通じて通知します。文書の改訂によって、既に保存した合意時点の本文や条件を最新版へ差し替えることはありません。

## 第2条（申込み及び当社の自動承諾）

1. 申込者は、対象の請求アカウントについて申し込む権限を持つ有効なポータル管理者である必要があります。申込者は、対象会社等を代表して申し込む権限があることを明示確認します。
2. 申込者は、基本約款、本約款、サービス仕様書及び提示された申込条件の固定版を確認し、必要文書ごとに明示的に同意して申し込みます。別途クラウドサインによる締結は必要ありません。
3. 当社は、本人、所属、申込権限、選択条件及び必要な同意を検証した有効な申込みをシステムにより自動承諾します。本契約は当社の自動承諾時に成立します。通常の申込みを人手承認待ちとはしません。申込受付、申込者の同意、当社承諾、契約登録及び利用可能の状態は区別して記録します。
4. 本約款にいう申込日は、当社システムが有効な申込みを受け付けた日本時間の日付とし、無料期間及び契約・課金期間の算定基準とします。同じ申込みの再送や処理の再開によって申込日を処理完了日へ変更しません。条件を変更して承諾する場合は、変更後の条件を再提示し、申込者の再同意を得ます。

## 第3条（受付プラン及び独立した複数契約）

1. 本オンライン申込で選択できるプランは、カジュアルプラン及びメンバーズプランです。トライアルは当社が営業上特別に付与するもので、本オンライン申込の対象ではありません。有料プランの申込月無料とは別の扱いです。
2. 同一請求アカウントに複数の本契約を申し込めます。各申込みは独立した新規契約であり、既存契約を変更又は置換しません。新規契約ごとに第5条の無料期間及び課金開始を適用し、課金開始後は各契約の月額料金が個別に発生します。
3. 対象の請求アカウントに既存のメンバーズ契約がある場合、同じプラン又は異なるプランのいずれでも重複契約となる旨を表示します。申込者は、別契約及び別月額料金が追加されることを確認して申し込めます。
4. 同じ申込操作の再送又は二重送信は、追加契約の意思表示とは扱いません。別の明示的な申込操作による追加申込みと区別します。
5. ブーストオプションの追加及び既存契約のプラン変更は、今回のオンライン新規申込に含みません。本約款への同意のみでこれらの追加契約や変更を開始しません。

## 第4条（提供範囲及び料金）

1. 初期費用は0円です。月額料金及び基本的な提供範囲は次のとおりです。

| 項目 | カジュアルプラン | メンバーズプラン |
|---|---|---|
| 月額料金（税抜） | 10,000円 | 50,000円 |
| 月額料金（消費税10％込み） | 11,000円 | 55,000円 |
| 対象チーム・ポータルアクセス枠 | 1名 | 3名 |
| QA | 月5回まで | 月20回まで |
| 作業支援 | なし | 月5時間まで |
| 定例会 | なし | 月1回（Web） |
| PoC計画・実行支援、セキュリティレビュー | なし | AIベース |
| AWSディスカウント | 3％ | 5％ |

2. AWSディスカウントは対象のAWSクラウド契約で定める割引上限内に限ります。加入のみで上限を超える割引又は他社アカウントへの無条件の割引を提供するものではありません。
3. 対応時間は平日10時から17時まで、対応はベストエフォートです。具体的な応答、解決又は復旧の時間及び24時間の対応は保証しません。障害の調査・切り分け・復旧、即時応答を要する緊急対応等は原則対象外です。ただし、課題として事前に定義した場合はサービス仕様書に従います。

## 第5条（申込月無料及び課金開始）

1. 申込日の属する暦月の料金は無料です。申込日から30日間の無料期間を設けるものではありません。無料期間にも選択したプランの条件を適用します。
2. 課金開始日は申込月の翌月1日とし、以後は暦月単位で月額料金を課金します。
3. 無料の申込月には通常解約できません。通常解約は初回課金月以降に行えるものとし、初回課金月に通常解約する場合にも1か月分の月額料金が発生します。契約違反等に基づく第12条の解除とは区別します。

## 第6条（契約期間及び自動更新）

1. 初回の契約期間は申込日から、課金開始日を起点とする12か月間の末日までです。初回は申込月の残日数に加えて12か月となります。
2. 第7条による解約申出がなければ、契約満了日の翌日から12か月間自動更新し、以後も同様とします。
3. 年次の契約期間は、12か月分の利用又は支払を強制する最低利用期間ではありません。契約者は初回課金月以降、年次期間の途中でも第7条により通常解約できます。年次期間の残月分を一括請求する扱いにはしません。
4. 例として、2026年11月12日申込の場合、無料期間は2026年11月30日まで、課金開始日は2026年12月1日、初回契約期間の末日は2027年11月30日です。解約申出がなければ2027年12月1日から2028年11月30日まで更新します。

## 第7条（通常解約及び課金停止）

1. 契約者は初回課金月以降、当社が案内する申出窓口又は書面により解約を申し出ることで、申出を当社が受け付けた月の末日に本契約を終了できます。年次満了日の1か月前その他の追加の申出期限は設けません。基本約款第15条の所定用紙及び翌月末以降の解除日の定めに代えて本条を適用します。
2. 解約月の月額料金は満額とし、日割り計算は行いません。解約月末までは利用可能とし、翌月以降の課金を停止します。
3. 前条の例で2026年12月中に解約を申し出た場合、2026年12月31日に終了し、12月は1か月分の満額です。2026年11月中の無料解約はできません。
4. 本オンライン新規申込にはオンライン解約の操作機能は含みません。契約者は当社の運営担当者へ申し出ることができます。契約終了後のサポートについて当社は義務を負いません。

## 第8条（請求及び支払）

1. 当社は利用料金を毎月末に締め、5営業日以内に契約者へ請求書を提出します。
2. 支払方法は当社が定める方法から契約者が選択し、支払条件は次の各号によります。
   - 銀行振込の場合、契約者は当該利用月の翌月末までに当社へ支払うものとします。
   - 口座振替の場合、当該利用月の翌月のうち、請求書等により事前に案内する指定振替日に、契約者の指定口座から振り替えます。
   - クレジットカードの場合、当社は当該利用月の翌月の当社指定日にカード決済を行い、その予定日を請求書等により事前に案内します。契約者のカード会社に対する支払期日及び口座引落日は、契約者とカード会社との契約に従います。
3. 第1項の請求書提出期限は、基本約款第20条第1項の請求書発行期限に優先します。基本約款第20条のその他の定めは引き続き適用します。
4. 申込み又は年次更新の処理自体を、請求書の作成又は決済とは扱いません。
5. 契約者又は当社から事前の申出があり双方が合意した場合には、本業務が月内に実施されない場合にも、当該月の利用料金は発生します。第5条の無料期間の扱いは変わりません。

## 第9条（守秘義務）

1. 契約者及び当社は、本契約の各条件に関する情報その他本契約の締結に関連して相手方から受領した秘密情報の一切を機密として取り扱い、相手方の事前の書面による同意なく第三者へ開示しないものとします。この義務は契約終了後も存続します。
2. 前項は、次の情報には適用しません。
   - 既に公知である情報
   - 開示された当時、受領者が既に知っていた情報
   - 開示後、受領者の責によらず公知となった情報
   - 秘密保持義務を負わず、適法に第三者から取得した情報
   - 法令、政府当局又は裁判所の命令に基づき開示が要求された情報
   - AWSより公開される情報
3. 本契約の守秘義務及びその例外には、基本約款第25条に優先して本条を適用します。

## 第10条（損害賠償及び責任）

契約者及び当社は、本契約に違反して相手方に損害を与えた場合、相手方に対し、その違反に起因して生じた損害を賠償するものとします。本契約の責任配分については、基本約款第23条及び第24条の当社の包括的な免責の定めに優先して本条を適用します。サービスの対象範囲及び保証しない事項は、第4条及びサービス仕様書によります。

## 第11条（反社会的勢力の排除）

1. 契約者及び当社は、現在及び将来にわたり、自己、自己の役員及び実質的に自己の経営を支配する者が暴力団、暴力団員その他これらに準ずる反社会的勢力に該当せず、これらと一切関係を有しないことを表明し、確約します。
2. 契約者及び当社は、自ら又は第三者を利用して、暴力的な要求、法的責任を超える不当な要求、詐術・脅迫、業務妨害その他これらに準ずる行為をしないことを表明し、確約します。
3. 相手方が前二項に違反したとき又は違反していたことが判明したときは、何らの催告を要せず直ちに本契約を解除できるものとし、その解除によって相手方に生じた損害を賠償する義務を負いません。

## 第12条（契約違反等による解除）

1. 契約者又は当社のいずれかが本契約に違反した場合、その相手方は書面により本契約を解除できます。
2. 当社に次の事由が生じた場合、契約者は直ちに本契約を解除できます。
   - 重大な過失又は背信行為
   - 支払の停止、仮差押、差押、競売、破産、民事再生、会社更生、会社整理又は特別清算の申立て
   - 手形交換所の取引停止処分
   - 公租公課の滞納処分
   - その他これらに準ずる、本契約を継続し難い重大な事由
3. 本条及び前条に基づく解除は、第7条の通常解約と区別します。本条に定めのない当社による解除事由には基本約款第17条を適用します。

## 第13条（権利義務の譲渡禁止）

契約者及び当社は、相手方の事前の書面による承諾なく、本契約に定める自己の権利義務の全部又は一部を第三者に譲渡し、又は担保に供することはできません。本契約には基本約款第10条に優先して本条を適用します。

## 第14条（合意及び承諾の記録・双方保管）

1. 当社は、申込番号及び契約番号と関連付けて、提示した文書の本文、名称、版、施行日、内容のハッシュ値及び取得元の固定版、提示条件、対象請求アカウント、選択プラン、申込者の識別情報、申込権限の確認根拠、必要文書ごとの同意及び日時、重複警告等の確認内容、当社自動承諾の日時・判断方針、契約登録並びに更新・終了・再同意・処理再開等の履歴を保存します。
2. 前項の記録は追記型で関連付け、改訂後も当時の提示文書及び条件を再現できるようにします。同意又は契約終了を契機として過去の記録を最新版へ上書きし、又は物理削除することはありません。
3. 当社は、本人又は権限を持つ利用者が申込控えを再表示し、保存できるようにします。当社による記録の保管及び契約者への控えの提供をもって双方の保管に対応します。他の顧客の記録を提供しません。
4. 合意及び承諾の記録は、契約終了後も監査及び契約内容確認のため保持します。保持期間、例外的な削除手続及びバックアップの取扱いは当社の記録保管方針で定め、通常のサービスデータの取扱いと区別します。

## 第15条（準拠法及び管轄）

本契約は日本法を準拠法とし、本契約に関する紛争については大阪地方裁判所を第一審の専属的合意管轄裁判所とします。本契約には基本約款第26条に優先して本条を適用します。

## 第16条（協議）

本契約に定めのない事項又は本契約の解釈に疑義が生じた場合、契約者及び当社は誠実に協議し、円満に解決するものとします。
