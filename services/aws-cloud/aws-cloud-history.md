# AWSクラウドサービス決済代行・新規発行オンライン契約条件 変更履歴

## 第1版 - 2026年11月14日

### 新規オンライン申込用条件の作成

- 新規AWSアカウント発行及び決済代行のオンライン申込だけを対象とし、既存AWS契約・移管・他サービスを変更しない。
- CloudSign契約書の確認資料を基に、AWS公表料金、米ドル小数点以下2桁への四捨五入、当社供与特典の加算復元（顧客独自登録分を除く）、みずほ銀行の米ドル月中平均、円換算端数切上げ、前月調整、請求・支払、契約期間、Organizations管理及び実脱退による終了を記載する。確認資料の範囲は根拠対応表に記録する。
- 2026年11月14日のユーザー確定事項により、当社初期費用無料・統一割引なし・特別要件は別途契約とする。割引率を推定せず、割引額の端数処理・解約月の割引日割りは今回の提供条件へ入れない。
- ユーザー明示条件に基づき、ベーシック・スタンダード・アドバンスド・マネージドの全4プランを受付対象とする。表示プランから1つを明示選択し、料金・提供範囲等を固定して同意を得る。
- 全申込で基本約款・AWS専用条件・AWSサポート約款の3文書に同意し、無料プランも含め当社承諾時に選択したAWSサポート契約も成立させる構成を実装設計として採用する。ユーザーが明示した受付・料金条件と、文書構成の設計判断は出典を区別する。
- CLI 3.1.110で確認されたマネージドの最低100,000円・公開範囲と、既存Invoiceの3〜20%段階式を明示する。各帯を円未満切上げして積み上げ、最低額と比較する。単一料率又は個別料率選択に置き換えない。構築支援7日、事務24h・一般12h・本番4h、調査・復旧・インシデント・マルチアカウント・監視・障害一次二次・アドバイザリー・顧客指定コミュニケーションを列挙し、詳細と段階表を固定申込条件にも表示・保存する。
- 当社裁量によるAWSへの問合せ・エスカレーション、請求代行可能時の課金開始、当該新規契約に限る遅延損害金14.6％を記載する。既存基本約款の14.5％は変更しない。
- 追加共有された正本原文から、RI対象6サービス・Savings Plans・AWSクレジットの購入及び利用、無料利用枠、Organizations由来の制限、root使用及び顧客のAWSサポート変更・ケース取扱いの制限と、希望時の個別協議を反映する。中国・GovCloud等は割引対象外であり地域利用禁止には変えない。SCP等の実装要件を新設しない。
- 保証金の3条件と金額・期間・返還等の協議、相互の契約違反による賠償及び当社の直近1か月分の納入済み委託料上限、日本法及び大阪地方裁判所の第一審専属的合意管轄を正本原文から反映する。基本約款の損害賠償・完全免責・管轄に対する専用例外を明示する。
- 本人メールのIAMユーザー、Portalで本人のみが初期パスワード確認・初回変更必須、MFA設定、MFAなしの初期設定用例外と管理制限、アクセスキー自動発行なし、Portal管理選択の意味を説明する。本人だけPortal確認・初回変更必須の追加回答を反映した。サポート用アクセスは当社初期設定で既存サポート約款第6条の顧客による別途提供に代える。既存サポート約款本文は変更しない。
- サポート初月無料・解約月非日割りの追加回答を反映する。初月はAWS作成日の属するJST暦月、その翌月1日から課金と具体化する。課金開始日未到来で終了した場合は徴収せず、開始後の解約月は満額とする。既存サポート約款第14条・第16条と照合し、Consoleの既存手入力・presetと新規受付の条件を区別する。既存契約の開始月・料金は変更しない。
- Portalからの申込と、解約の書面通知は区別する。Portal通知を解約の書面に代える規定や、新しい移管・データ削除条件は追加しない。
- 基本約款第9版の第3条第8項に、当該新規契約だけの優先例外を追加する。第8版全文を保存し、Relay及びMail Ver.2の文書・固定同意を維持する。
- 出典、原本の確認範囲、既存文書との対応及び将来のフィードバック項目は[根拠対応表](./aws-cloud-source-map.md)に記録する。
