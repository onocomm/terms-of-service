# AWSクラウドサービス決済代行・新規発行オンライン契約条件

**制定日**: 2026年11月14日
**施行日**: 2026年11月14日
**版**: 第1版

---

## 第1条 (適用範囲及び適用関係)

1. 本条件は、当社ポータルサイトから新規に申し込み、株式会社オノコム（以下「当社」という）が承諾するAWSクラウドサービスの決済代行及び新規AWSアカウント発行の契約（以下「本契約」という）に適用します。
2. 本申込には、[オノコムサービス契約約款（基本約款）](../../contract_jp.md)、本条件及び[AWSサポートサービス契約約款](../aws-support/aws-support-contract.md)の3文書を適用します。本条件に具体的な定めがある事項は、基本約款及びAWSサポートサービス契約約款に優先し、本条件に定めのない事項は、適用される各約款によります。
3. 本条件は、既に成立しているAWS契約、既存アカウントの契約又は移管、他サービスの契約条件及び過去の同意内容を変更するものではありません。

## 第2条 (申込及び契約の成立)

1. お客様は、申込時に提示される基本約款、本条件及びAWSサポートサービス契約約款の3文書並びに当該申込の料金・サポート等の個別条件を確認し、明示的に同意して申し込むものとします。
2. 本契約及び選択したプランに係るAWSサポート契約は、当社が申込を承諾した時に成立します。申込の送信だけをもって当社の承諾又はAWSアカウントの発行完了を意味するものではありません。
3. 同意対象の文書の版及び本文並びに当該申込の個別条件を固定して記録します。文書の改訂又は最新表示への切替により、過去の申込における同意内容を差し替えません。

## 第3条 (初期費用、割引及び特別な要件)

1. 本申込に係る当社の初期費用は無料とします。AWS利用料金及び申込時に合意したサポート等の料金を無料とするものではありません。
2. 本オンライン契約では、当社の統一割引を適用せず、割引条件を「割引なし」とします。
3. 個別の構築、移行、運用その他の特別な要件については、本申込への同意だけで作業の実施又は料金を確定せず、対象、範囲、料金その他の条件を別途契約するものとします。

## 第4条 (AWS利用料金の算定)

1. AWS利用料金はAWSの公表料金を基礎とし、米ドルの小数点以下第3位を四捨五入して小数点以下2桁までで算定します。
2. 当社が供与するクレジット、クーポン、リザーブドインスタンス、セービングプラン、ボリューム割引及び無料特典による減額分は、お客様が独自に登録した分を除き、加算復元して算定します。このため、当社の請求額はAWS上の表示額と異なる場合があります。
3. 前月の調整分がある場合は、調整後の金額を当月の対象とします。
4. 日本円への換算には、みずほ銀行が公表する米ドルの月中平均を使用し、換算後の円未満の端数を切り上げます。料金には消費税等相当額を加算します。
5. 本契約では統一割引を適用しません。リザーブドインスタンス、セービングプラン、クレジットの購入、Registrar及びMarketplaceについても、統一割引の対象外であることを理由に請求対象から除外するものではありません。

## 第5条 (サポートの条件)

1. お客様は、ベーシック、スタンダード、アドバンスド又はマネージドの4つのサポートプランから1つを明示的に選択するものとします。提供範囲、料金、算定方法その他の個別条件は、申込時に表示し、お客様が同意した内容によるものとします。サポートの初月無料及び課金開始は第7条第4項、解約月の取扱いは第9条第3項によります。プランの選択により、表示・合意した範囲を超えるサポートを提供するものではありません。
2. 申込時に表示されるプランのサポート料が無料である場合を含め、全ての本申込にAWSサポートサービス契約約款を提示し、同意を得るものとします。サポート料が無料であることは、AWS利用料金等も無料であることを意味しません。
3. 当社からAWSへのサポート問合せ又はエスカレーションを行うかどうかは、当社の裁量によります。お客様は、その実施を当社に強要することはできません。
4. マネージドの月額サポート料は、AWSサポートサービス契約約款第4条に従う算定対象額を次表の各帯に分け、各帯に該当する金額に当該帯の料率を乗じて円未満を切り上げた額を合計し、その合計額と月額最低料金100,000円（税別）のいずれか高い額とします。算定対象額全体に単一の料率を適用するものではなく、料率をお客様が個別に選択するものでもありません。段階表、各帯の端数処理、最低料金及び提供範囲を申込時の個別条件として表示し、固定して同意を得るものとします。

| 算定対象額の帯（日本円・税別） | その帯に該当する部分の料率 |
|---|---|
| 20,000,000円を超える部分 | 3% |
| 10,000,000円を超え20,000,000円以下の部分 | 5% |
| 5,000,000円を超え10,000,000円以下の部分 | 7% |
| 4,000,000円を超え5,000,000円以下の部分 | 10% |
| 3,000,000円を超え4,000,000円以下の部分 | 13% |
| 2,000,000円を超え3,000,000円以下の部分 | 15% |
| 1,000,000円を超え2,000,000円以下の部分 | 17% |
| 1,000,000円以下の部分 | 20% |

5. マネージドの提供範囲は、構築支援7日間、事務的な問い合わせ24時間以内、一般的な技術的な問い合わせ12時間以内、本番環境の技術的な問い合わせ4時間以内、調査・状況確認、復旧作業、インシデント対応、マルチアカウント対応、サービス監視、障害一次・二次対応、アドバイザリー及びお客様が指定するコミュニケーション方法とし、詳細は申込時に表示して固定する条件によります。第7条第4項による初月無料及び第9条第3項による解約月の取扱いは、マネージドにも適用します。

## 第6条 (AWSアカウントの管理)

1. 本申込に基づき新規発行するAWSアカウント（以下「対象アカウント」という）は、当社指定のAWS Organizations配下とし、発行後に本申込に紐付けて確定します。対象アカウントのルートユーザーは当社が管理し、お客様による使用を制限します。
2. 当社は、申込時に当社ポータルサイトの有効な登録情報から確認した申込者本人のメールアドレスをユーザー名とするIAMユーザーを対象アカウントに初期設定します。初期パスワードは、当社ポータルサイト上で申込者本人のみが確認できるものとし、本人は初回ログイン時にパスワードを変更し、多要素認証（MFA）を設定するものとします。MFAを使用しないセッションでは、本人のパスワード変更及びMFA登録等の初期設定に必要な最小限の操作を除き、管理操作を制限します。MFAの登録だけでは管理操作は可能とならず、MFAを使用した再ログイン等が必要です。アクセスキーは自動発行しません。
3. AWSサポートサービス契約約款第6条のIAMユーザー提供については、本申込では当社が対象アカウントへのサポートに必要なアクセス権限を初期設定することで、お客様による別途のIAMユーザー提供に代えるものとします。このサポート用のアクセス権限と、前項の申込者本人のIAMユーザーとは区別します。
4. お客様は、対象アカウントをオノコムポータルで管理するかどうかを申込時に選択し、その選択内容を本申込の条件として記録します。この選択だけをもって、サーバー作成、構築又は個別運用の作業を申し込んだものとはせず、ルートユーザーの使用制限又はMFAによる管理操作の制限を解除するものでもありません。

## 第7条 (請求及び支払)

1. 本決済代行の課金は、対象AWSアカウントが当社指定のAWS Organizationsのメンバーとして登録され、当社による請求代行が可能となった時点から開始します。契約の締結日と課金開始時点は区別します。サポートの初月無料及び課金開始は、第4項によります。
2. 当社は利用料金等を毎月末日に締め、5営業日以内にお客様へ請求書を提出し、お客様は当社の請求に基づき翌月末日までに当社に支払うものとします。
3. 本契約に係る支払遅延の遅延損害金の年率は、基本約款第20条第3項の年率14.5％に代えて14.6％とします。
4. 本申込に係る全てのサポートプランは初月無料とします。初月とは、対象アカウントの作成日が属する日本時間の暦月をいい、サポートの課金開始はその翌月1日（日本時間）とします。AWSサポートサービス契約約款第14条の課金開始について、本申込ではこの作成月を基準として具体化します。申込日、当社承諾日又は準備完了日の月に置き換えるものではなく、AWS利用料金等を初月無料とするものでもありません。

## 第8条 (契約期間及び更新)

本契約の期間は締結日から1年間とします。有効期間満了の1か月前までにお客様又は当社から相手方に書面による解約の申入れがない場合は、さらに1年間更新し、以後も同様とします。

## 第9条 (解約及び終了)

1. お客様は、解約希望日の1か月前までに当社へ書面による解約の申入れを行うものとします。お客様及び当社は、解約及び対象AWSアカウントのAWS Organizationsからの脱退について協議するものとします。
2. 本契約の終了及び本サービスの利用料金等の請求停止は、対象AWSアカウントが当該AWS Organizationsから実際に脱退した時点とします。解約の申入れを受け付けたことだけをもって、脱退、契約終了又は請求停止が完了したものとはしません。
3. 前項の終了月におけるサポート料は、AWSサポートサービス契約約款第16条第2項及び第3項と同じく、日割り計算を行わず1か月分の全額とします。ただし、第7条第4項のサポート課金開始日が到来する前に終了した場合は、初月無料によりサポート料を請求しません。

## 第10条 (制限事項)

1. 本契約中の対象アカウントには、本条に定める制限が適用されます。お客様が制限事項について実施したい場合は、当社と個別に協議するものとします。
2. リザーブドインスタンス（EC2、RDS、ElastiCache、OpenSearch、Redshift、DynamoDB）、Savings Plans及びAWSクレジット（Amazon CloudFront Security Savings Bundleを含む）の購入及び利用は制限されます。
3. AWSが提供する無料利用枠の利用は制限されます。
4. その他、AWS Organizationsのメンバーアカウントに登録されることによって制限される一切の事項が、対象アカウントにも適用されます。
5. ルートユーザーは当社が管理し、お客様による使用は制限されます。
6. お客様は、AWSサポートのプラン変更及びサポートケースの取扱いを行うことはできません。ただし、お客様が希望する場合は、お客様及び当社の協議の上、お客様がAWSサポートの費用を負担して契約することができるものとします。
7. 中国リージョン、GovCloud及びその他特別な申請によって使用が許可されるリージョンは、割引対象外とします。なお、本契約には第3条第2項のとおり統一割引を適用しません。

## 第11条 (保証金)

当社は、お客様に対して、次のいずれかに該当する場合、保証金の預託を請求することができます。保証金の預託の請求が生じた場合は、保証金の額、期間及び返還等の条件について、お客様及び当社の協議の上、別途定めるものとします。

1. 委託料が3か月間連続して月額100万円を超えたとき
2. 委託料の支払が1回以上滞ったとき
3. 当社が保証金の預託が必要だと判断できる合理的な理由が生じたとき

## 第12条 (損害賠償)

本契約に係る損害賠償については、基本約款第23条及び第24条にかかわらず、お客様及び当社は、本契約に違反して相手方に損害を与えた場合、相手方に対し当該違反に起因して生じた損害を賠償するものとします。ただし、当社がお客様に対して負う損害賠償の金額は、お客様から当社へ納入された直近1か月分の委託料を超えないものとします。

## 第13条 (準拠法及び管轄裁判所)

本契約は、日本法を準拠法とし、本契約に関してお客様及び当社の間に紛争が生じた場合は、基本約款第26条にかかわらず、大阪地方裁判所を第一審の専属的合意管轄裁判所とします。
