## 根拠と確認範囲

1. CloudSign正本: Google Driveの「AWSクラウドサービス契約書（決済代行、割引プラン、サポートのまとめ）.docx」。ファイルID `1kV5LJzYGnoyY2KSJmVg09BFD6kD-An1f`、更新日2024年12月24日。
2. ユーザー明示条件（2026年11月14日）: 当社の初期費用無料、割引なし、特別要件は別途契約。条件の正本はCloudSign契約書、サポート価格の正本はonocomm-cli単価表又はonocomm.jp。本人IAM・MFA・Portal管理フラグもユーザー要件である。
3. 実装設計: 申込時に表示した料金・提供範囲等を固定して同意を得る。文書構成の設計判断はユーザー明示条件と区別する。マネージドの段階表と提供範囲は、既存計算及び公開範囲に基づく。
4. 作成元のTerms mainは `9cc1e0935a78e7424adef3cd71046558ed5717c4`。既存[基本約款第8版](../../archive/v8_2026-11-14.md)、[AWSサポート約款](../aws-support/aws-support-contract.md)、[AWS構築支援約款](../aws-build/aws-build-contract.md)を照合した。
5. CloudSign確認資料: USD2桁への四捨五入、当社供与特典の加算復元（顧客独自登録分を除く）及びAWS表示との差異、AWS問合せ・エスカレーションの当社裁量、請求代行可能時の課金開始、遅延損害金14.6％等の要約・追加事項。
6. CloudSignの原文確認範囲: 同じ正本の「制限事項」「保証金」「損害賠償」「準拠法及び管轄裁判所」の4見出し。確認資料に条番号がないため、見出しで特定する。
7. 実装設計として採用した文書構成: 全申込で基本約款・AWS専用条件・AWSサポート約款の3文書に同意し、表示プランの1つを明示選択してAWSサポート契約も成立させる。無料プランも同じ構成とする。既存AWSサポート約款は改変せず、新規発行・初期本人IAMとの差異を専用条件で整理する。これらは文書構成の設計判断であり、ユーザーの個別発言の引用ではない。
8. オンライン化の実装根拠はConsoleの `docs/aws-cloud-online-signup.md:11` から13行（本人IAM・MFA・Portal管理選択）、`docs/aws-cloud-signup-protocol.md:16`（申込と対象アカウントの紐付け）、`backend/resources/AwsCloudSignup/iam.ts:15` の `createIamPreparation`、`backend/resources/AWSAccountProvisioningShared/mfa.ts:37` の `buildInitialMfaGuardPolicy`。既存の運営者アクセス設定と本人IAMを区別する。これらはCloudSign由来ではなく、今回の新規オンライン発行の説明である。
9. ユーザー明示条件: マネージドを含む全4プランを選択対象とする。初期パスワードは本人だけがPortalで確認し、初回変更を必須とする。サポートは初月無料、解約月の日割りなし。初月をAWSアカウント作成日の属するJST暦月、その翌月1日を課金開始日とするのは、この条件の実装設計上の具体化である。解約月は満額だが、課金開始日前に終了した場合は徴収しない。決済代行の登録時課金開始とは区別する。
10. マネージド料金・範囲: onocomm-cli `3.1.110` の再取得された単価表で、最低100,000円・公開料率3〜20%及び提供範囲を確認した。具体的な段階表は `onocomm-system-invoice-create/lambda/services/aws-service.ts` の既存計算に基づく（commit `43d8d508d1aab0fd0c48056f4efd707aa309ba0b`、431行から500行）。各帯の切上げ・積上げ・最低額比較をソース照合した。これはCloudSign雛形の空欄を補う現行請求計算の明示であり、新しい個別料率選択・課金方式の新設ではない。

CloudSignの確認資料は、要約・追加事項と上記4見出しの原文です。4見出しは原文と条文を照合して反映しています。契約書全文を再取得した網羅的な照合ではなく、確認資料にない条項まで網羅したものとは扱いません。法務専門家による確認は未実施です。

原文の「甲」はお客様、「乙」は当社に置き換え、数字・月の表記と文体を統一しています。保証金及び賠償上限の基準語「委託料」は維持し、未共有の定義を推測してAWS利用額等へ読み替えていません。

## 今回適用しない雛形項目

CloudSign雛形の統一割引の合意率欄、割引額の端数切捨て及び解約月の割引日割りは、将来の割引プラン対応時の原本照合事項として残します。今回のユーザー指定は「割引なし」のため、これらを今回の申込条件に含めたり、割引日割りをAWS利用料金全体又はサポート料の日割りへ流用したりしません。
