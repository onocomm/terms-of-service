# メールサービスVer.2サービス利用条件

**制定日**: 2026年11月13日
**施行日**: 2026年11月13日
**版**: 第1版
**株式会社オノコム**

## 第1条（適用及び優先関係）

1. 本条件は、2026年11月13日以降に株式会社オノコム（以下「当社」といいます）のポータルサイトから新規に申し込み、当社が承諾するメールサービスVer.2の標準契約に適用します。メールサービスVer.1の新規申込、既存のメール契約の変更・移行・再同意は対象としません。本条件の制定又は改訂によって、既存契約の条件及び過去の同意記録を自動的に変更しません。
2. 本条件は、オノコムサービス契約約款（以下「基本約款」といいます）及びメールサービスVer.2オンライン申込条件（以下「オンライン申込条件」といいます）と併せて適用します。具体的な定めが異なる場合は、オンライン申込条件、本条件、基本約款の順で優先し、定めのない事項には基本約款を適用します。
3. 本オンライン申込は標準条件による新規契約です。既存の見積、個別契約又は特約を本申込によって変更しません。これらと異なる条件での申込を希望する場合は、当社にお問い合わせください。

## 第2条（提供単位及び利用準備）

1. お客様のドメイン名1つにつき1契約としてメールサービスを提供します。対象ドメイン名及び請求アカウントは申込時に明示します。
2. 開通には、オンライン申込条件に定める専用DNS TXTレコードによる対象ドメイン名の管理権限確認を必要とします。申込受付又は当社承諾だけで、直ちにメールを送受信できる状態となるものではありません。
3. 申込者本人を初期管理者の招待先とします。初期管理者の招待及び本人による招待の受諾と、ドメインの開通、メールアカウントの作成並びにメール配送用DNSの切替は別の手続きです。
4. 本申込のみでお客様の既存メールサービスを解約し、既存メールを移行し、又は既存DNSのMX等を変更することはありません。お客様側のDNS設定及びメールソフト等の設定と、別途合意する当社の個別作業を区別します。

## 第3条（基本料金及び容量超過料金）

1. 1ドメイン・1契約あたりの標準料金は次のとおりです。いずれも税別とし、消費税等を別途加算します。

| 項目 | 条件 |
|---|---|
| 月額基本料金 | 500円 |
| 基本料金に含む保存容量 | 10GB（10,000,000,000バイト） |
| 容量超過料金 | 超過分1GBあたり月額10円 |
| 容量の単位 | 1GB＝1,000,000,000バイト（十進） |
| 超過分の端数 | 1GB未満を1GBに切り上げ |

2. 課金対象容量は、対象ドメイン配下の保存容量合計を定時観測した値の利用月内の最大値です。毎時の観測値に基づくもので、観測間の連続的な瞬間最大値ではありません。
3. 基本容量を差し引いた超過バイト数が正の場合、その値を1,000,000,000で除し、整数に切り上げたGB数に10円を乗じます。10GB以下の超過料金は0円、10GBを1バイト超過した場合の超過料金は10円です。
4. 登録月の取扱いは第5条によります。保存容量の増減により、登録月以外の月額基本料金を日割り計算することはありません。

## 第4条（任意の有料サポート及び個別作業）

1. 有料サポートは申込時に選択する任意のオプションです。選択しない場合、本オプションの料金は発生しません。
2. 有料サポートを選択した場合、対象ドメインごとの月額サポート料金は、20,000円と、課金対象アカウント数に200円を乗じた額の、いずれか高い額です。いずれも税別です。例えば50アカウントの場合は20,000円、120アカウントの場合は24,000円です。
3. 課金対象は、対象ドメインのPOP又はSMTP認証が可能なアカウントです。同じアカウントに複数の認証情報又は別名がある場合に重複して数えず、メーリングリストは含めません。毎時観測した対象アカウント数の利用月内の最大値で計算します。
4. 第5条の登録月無料は、月額基本料金及び容量超過料金だけに適用します。有料サポートは登録月も前二項により課金し、初月無料とはしません。
5. 導入、移行、設定代行その他の個別作業の費用及び提供範囲は、別途の見積等により提示し、合意します。本条件又は本申込によって、それらの費用を0円とし、又は追加作業を自動発注したものとは扱いません。有料サポートの選択を、これらの個別作業すべてを無制限に含むものとは扱いません。
6. メールウイルスチェック等の別契約オプションは、本申込に自動的に含めません。既存の別契約の料金及び条件は変更しません。

## 第5条（登録月無料及び月単位の課金）

1. 契約登録日は、対象ドメインの当社メール基盤での利用準備が成功した日本時間の日付とします。その日の属する暦月を登録月とし、月額基本料金及び容量超過料金は無料とします。登録日から30日間無料とするものではありません。登録月内に解約する場合にも、この無料の取扱いを適用します。
2. 契約成立とメールドメインの利用準備成功は区別します。利用準備の成功前は登録日及び無料対象月を未確定とし、申込時点で将来又は過去の無料月を生成しません。準備未完了の期間について無料月を消費させ、又は本契約の基本・容量・有料サポート料金を課金することはありません。
3. メールドメインの利用準備成功は、初期管理者による招待受諾又はお客様側のメール配送用DNSの切替とは別の状態です。利用準備成功後にこれらの操作を待っていることを理由として、登録日及び無料対象月を遅らせ、又は課金開始を無期限に延期しません。
4. 当社は利用準備成功の記録に基づく契約登録日及び無料対象月を申込控えに記録します。同じ申込操作の再送又は処理の再開によって、新しい契約登録月又は無料月を重ねて付与しません。
5. 登録月の翌月以降は暦月単位で第3条の料金を計算します。有料サポートには登録月から第4条の料金を適用します。請求及び支払に関し本条件に定めのない事項は基本約款によります。

## 第6条（通常解約及び課金終了）

1. 契約者は、当社が案内する窓口から解約を申し出ることにより、当社が申出を受け付けた月の末日に本契約を終了できます。基本約款第15条第1項及び第2項の所定用紙・翌月末以降の解除日の定めに代えて、本項を適用します。この当月末解約は、本条件に同意して新規成立したメールサービスVer.2の契約だけに適用します。
2. 解約月の料金は月単位で計算し、日割り計算を行いません。登録月内の解約には第5条の月額基本料金・容量超過料金の無料を適用しますが、有料サポートの登録月無料は適用しません。
3. 解約月末で提供を終了し、翌月以降の本契約の料金は発生しません。既に発生した利用料金の請求及び支払と、サービスの提供終了を区別します。
4. 本条件は、ポータルサイトでのオンライン解約操作機能が提供済みであることを意味しません。また、他サービスの契約を一括して終了するものではありません。
